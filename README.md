# 📖 Библейская викторина (real-time, Kahoot-стиль)

Интерактивная викторина на знание Библии для живых мероприятий. Ведущий
открывает викторину на большом экране и показывает QR-код; участники сканируют
его телефонами, вводят имя и отвечают на вопросы. На каждый вопрос — 15 секунд.
После 10 вопросов — итоговый рейтинг.

## Стек

- **Next.js 15 + TypeScript** (App Router) — фронтенд и API-роуты, деплой на **Vercel**
- **Pusher Channels** — real-time (телефоны и экран подключаются к Pusher напрямую,
  поэтому serverless-ограничение Vercel на WebSocket не мешает)
- **Состояние игры — в памяти браузера ведущего** (экран админа = источник правды).
  База данных не нужна; ничего не сохраняется между играми.

## Как это работает

- **Экран ведущего (админ):** `/host` — выбор викторины, QR-код, лобби, вопросы с
  таймером и картинкой, показ правильных ответов и финальный рейтинг.
- **Участник:** `/?game=КОД` (ссылка в QR-коде) — ввод имени с **проверкой
  уникальности** (если имя занято — просит другое), затем крупные кнопки A/B/C/D.
- **Режимы викторин:**
  - **Вопросы** — обычный текстовый вопрос + 4 варианта (5 викторин, 50 вопросов).
  - **Селфи** — на экране «селфи» библейского героя; угадать, кто это, по сцене и
    обстановке; 4 имени-варианта (5 викторин, 50 вопросов).

## Локальный запуск

```bash
npm install
cp .env.example .env.local   # и впишите ключи Pusher (см. ниже)
npm run dev
```

Откройте экран ведущего: http://localhost:3000/host
Участник (для теста в другой вкладке/телефоне): ссылку с QR или `http://localhost:3000/?game=КОД`.

> Для теста на реальном телефоне в одной Wi-Fi-сети используйте адрес вида
> `http://<ваш-IP>:3000` (`npm run dev -- -H 0.0.0.0`).

## Настройка Pusher (бесплатно)

1. Зарегистрируйтесь на https://dashboard.pusher.com/ и создайте приложение
   (**Channels** → Create app). Выберите ближайший кластер (напр. `eu`).
2. Во вкладке **App Keys** возьмите `app_id`, `key`, `secret`, `cluster`.
3. Заполните `.env.local` (и переменные окружения на Vercel):

   | Переменная | Откуда |
   |---|---|
   | `PUSHER_APP_ID` | app_id |
   | `PUSHER_SECRET` | secret |
   | `NEXT_PUBLIC_PUSHER_KEY` | key |
   | `NEXT_PUBLIC_PUSHER_CLUSTER` | cluster (напр. `eu`) |

Бесплатного тарифа Pusher (100 одновременных подключений, 200k сообщений/день)
достаточно для зала на несколько десятков человек.

## Деплой на Vercel

### Вариант A — через GitHub (рекомендуется)

1. Залейте проект в репозиторий GitHub.
2. На https://vercel.com → **Add New → Project** → импортируйте репозиторий.
3. В **Settings → Environment Variables** добавьте 4 переменные Pusher из таблицы выше.
4. Deploy. Экран ведущего будет по адресу `https://<проект>.vercel.app/host`.

### Вариант B — через CLI

```bash
npm i -g vercel
vercel login
vercel            # первый деплой (preview)
# добавить переменные окружения:
vercel env add PUSHER_APP_ID
vercel env add PUSHER_SECRET
vercel env add NEXT_PUBLIC_PUSHER_KEY
vercel env add NEXT_PUBLIC_PUSHER_CLUSTER
vercel --prod     # продакшн-деплой
```

## Картинки для режима «Селфи»

Исходные селфи лежат в `src/selfie/` (в git не попадают — это 132 МБ) с именами
вида `01_Адам.png`: **имя файла — это имя героя и правильный ответ.** 50 героев
делятся на 5 викторин по 10 в порядке номеров.

После добавления или замены картинок запустите:

```bash
node scripts/import-selfies.mjs
```

Скрипт сожмёт картинки в `public/images/selfie/sNN.webp` и пересоберёт
селфи-викторины в `src/data/quizzes.json` (неверные варианты — герои того же пола
и эпохи).

## Контент

Все 100 вопросов — в одном файле `src/data/quizzes.json` (10 викторин по 10
вопросов). Добавляйте/правьте вопросы прямо там; у каждой викторины есть пробный вопрос
(поле `practice`) — он идёт первым и не влияет на очки.
